# Rise 音频素材检索清单

依据 [Rise-40小时成品版策划案](G:\UnityProject\Rise\Docs\Rise-40小时成品版策划案.md) 第 10 节“音效需求表”整理。优先顺序按文档要求执行：

1. 抓取成功
2. 蹬腿发力
3. 放绳发射
4. 锚点落位
5. 风声 / 呼吸 / 滑落 / 篝火

## 优先推荐库

### 1. Pixabay
- 适合：先快速补齐可商用素材，音乐和音效都够用。
- 许可：官方 FAQ 说明音乐和音效可用于商业和非商业项目，通常不强制署名；但音频偶尔会遇到 Content ID，需要保留下载时的许可证文件。
- 许可页：
  - https://pixabay.com/service/faq/
  - https://pixabay.com/service/license-summary/

### 2. Mixkit
- 适合：做动作反馈类 SFX，尤其是 hit / impact / wind / whoosh / metal。
- 许可：官方说明免费音效和音乐可用于商业和非商业项目，无需署名。
- 许可页：
  - https://mixkit.co/license/
  - https://mixkit.co/free-sound-effects/
  - https://mixkit.co/free-stock-music/

### 3. Freesound
- 适合：补很具体的拟音，比如岩石摩擦、绳索张力、特殊呼吸。
- 许可：必须逐条看 license。优先只拿 `CC0`；`CC-BY` 需要署名；不要直接用 `CC-BY-NC` 到商业项目。
- 许可页：
  - https://freesound.org/help/faq/

## 我建议你们的实际筛选顺序

1. 先在 Mixkit 里定 4 个核心交互：
   - `抓取成功`
   - `蹬腿发力`
   - `锚点落位`
   - `放绳发射`
2. 再用 Pixabay 补环境层：
   - `风`
   - `呼吸`
   - `篝火`
   - `滑落`
3. 如果某个动作缺非常具体的拟音，再去 Freesound 找 `CC0`。
4. BGM 最后再定，优先找 `ambient / tension / atmospheric`，并让它长期低于动作反馈。

## 当前最稳的结论

- 想最快落地：先用 `Mixkit + Pixabay`
- 想补更细的拟音：再加 `Freesound(CC0 优先)`
- 想避免后续授权返工：下载时把素材链接、作者名、许可页一起存档
