## 2. 实现顺序

### 阶段 1：背包纯数据层

目标：先让双背包逻辑可靠，不碰复杂 UI。

任务：

- 新增 `InventoryItemDefinition`
- 新增 `InventoryItemStack`
- 新增 `InventoryGrid`
- 新增 `PlayerInventory`
- 实现小背包 `4x4`
- 实现大背包 `6x6`
- 支持占格、旋转、堆叠、移动、移除
- 支持快速移动底层接口
- 支持总重量、重量等级计算

验收：

- 物品不能越界放置。
- 物品不能重叠放置。
- 旋转后占格正确。
- 同类物品能堆叠到上限。
- 小背包、大背包数据互不污染。

### 阶段 2：背包 UI 最小可用版

目标：先做能用的格子界面，不追求最终美术。

任务：

- 小背包界面。
- 大背包界面。
- 左键拖拽物品。
- 拖拽中 `R` 旋转。
- `F` 快速移动。
- 右键子菜单：使用 / 丢弃 / 详情。
- 详情提示显示 3 秒。
- 背包打开时冻结攀爬输入。

验收：

- 小背包可随时打开。
- 大背包只在休息状态打开。
- 拖拽失败会回到原位。
- 右键菜单不会对未选中物品误触发。
- 详情提示 3 秒后消失。

### 阶段 3：道具消耗接入

目标：锚点和攀山绳正式由小背包供给。

任务：

- `ToolController` 使用前检查 `PlayerInventory`。
- 锚点从小背包扣除。
- 攀山绳从小背包扣除。
- HUD 显示小背包内可用锚点/绳索数量。
- 数量不足时提示，不进入实际放置。

验收：

- 小背包无锚点时不能放置锚点。
- 小背包无绳索时不能放绳。
- 使用成功才扣除物品。
- 落点无效不扣除物品。

### 阶段 4：背包重量接入攀爬

目标：让资源取舍影响攀爬手感。

任务：

- 实现 `PlayerInventory.HoldDrainMultiplier`。
- 实现 `PlayerInventory.KickForceMultiplier`。
- `PlayerClimbController` 保持抓取消耗读取倍率。
- `PlayerClimbController` 蹬腿力读取倍率。
- HUD 显示轻装 / 中载 / 重载 / 超载。

验收：

- 轻装无惩罚。
- 中载保持消耗增加。
- 重载蹬腿明显变弱。
- 超载能被 HUD 明确提示。

### 阶段 5：休息系统状态机

目标：把现有“按 F 直接恢复”改成休息界面流程。

任务：

- 新增 `RestSessionController`。
- 接管 `PlayerClimbController.PerformRest()`。
- 进入休息时释放双手。
- 冻结玩家刚体。
- 隐藏人物表现。
- 摄像头移动到休息点。
- 显示右侧菜单：背包整理 / 烹饪 / 休息。
- 点击休息后才结算恢复并退出。

验收：

- 按 F 后不立即恢复属性。
- 人物隐藏。
- 攀爬输入不可用。
- 右侧菜单出现。
- 点击休息后恢复并退出。
- 退出后人物、摄像头、输入恢复正常。

### 阶段 6：休息菜单功能接入

目标：让背包和烹饪按休息类型开放。

任务：

- 短休息点背包整理只打开小背包。
- 短休息点烹饪按钮禁用。
- 短休息点休息按钮执行短休。
- 长休息点背包整理打开小背包 + 大背包。
- 长休息点烹饪按钮可用。
- 长休息点休息按钮执行长休并更新检查点。

验收：

- 短休不能打开大背包。
- 短休不能烹饪。
- 长休能整理大小背包。
- 长休能进入烹饪菜单。
- 长休结束后更新检查点。

### 阶段 7：烹饪系统

目标：长休息点内可消耗材料恢复长期属性。

任务：

- 新增 `CookingRecipeDefinition`。
- 新增 `CookingSystem`。
- 新增 `CookingUI`。
- 支持配方可制作/不可制作状态。
- 制作时消耗背包物品。
- 制作时恢复健康、饥饿、温暖、理智。

验收：

- 材料不足时不能制作。
- 材料足够时能制作。
- 制作后材料扣除。
- 属性恢复正确。
- 烹饪后仍停留在休息界面。

### 阶段 8：资源点搜索

目标：补上资源采集和逐秒揭示物品。

任务：

- 新增 `ResourceNode`。
- 新增 `LootTableDefinition`。
- 打开资源点后先显示轮廓。
- 每 1 秒揭示 1 个物品。
- 未揭示物品不能拖拽、不能 `F`、不能右键。
- 已揭示物品可移动到小背包。

验收：

- 资源点生成物品列表。
- 每秒只揭示一个物品。
- 未搜索完成物品不可操作。
- 已搜索完成物品可拿走。
- 资源点状态可记录。

### 阶段 9：音频与镜头完善

目标：把休息体验做完整。

任务：

- 休息镜头平滑移动到休息点。
- 退出休息镜头回到玩家。
- 风声降低到 25%-35%。
- 外部环境声降低到 30%-40%。
- 长休息点淡入篝火/帐篷内氛围。
- 退出休息时恢复混音。

验收：

- 进入休息有明显空间切换感。
- 风声不会突然硬切。
- 退出后音频恢复正常。
- 镜头不抖、不丢目标。
